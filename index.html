1. Historia y evolución de la web

La World Wide Web nació en 1989 (propuesta por Tim Berners-Lee en el CERN) y pasó de documentos enlazados y sitios estáticos (Web 1.0) a plataformas interactivas con contenido generado por usuarios (Web 2.0) y aplicaciones web modernas (Web 3.0, SPA, PWA y APIs).

Puntos clave de la clase:

  • Pilares iniciales (1990-1991): HTML (estructura), HTTP (transferencia) y URL (localización de recursos).
  • Arquitectura cliente-servidor: el cliente (navegador) solicita recursos mediante resolución DNS y el servidor responde con archivos o datos.
  • HTTP y HTTPS: HTTP es un protocolo petición-respuesta sin estado (stateless), mientras que HTTPS añade cifrado TLS/SSL para confidencialidad, integridad y autenticidad.

2. Etiquetas de HTML

HTML está formado por elementos que el navegador interpreta para mostrar contenido en pantalla, y se puede escribir en un editor de texto simple y probar en el navegador con extensión .html.

Conceptos y etiquetas de la Parte 1 (Laboratorio):

  • Estructura básica: <!DOCTYPE html>, <html>, <head> (con <title> y <meta charset="UTF-8">) y <body>.
  • Salto de línea (<br>): fuerza a continuar en la siguiente línea (no lleva etiqueta de cierre).
  • Párrafos (<p>...</p>): agrupan ideas separadas por un espacio; admiten <br> en su interior.
  • Títulos (<h1> a <h6>): definen jerarquía de encabezados, siendo <h1> el de mayor nivel.

3. Formularios

Un formulario con <form> permite que el visitante ingrese datos y los envíe al servidor (indicando destino en action y método como method="post")[cite: 16]. Cada campo necesita su atributo name para identificarse[cite: 17].

Controles principales vistos en clase:

  • <input>: cuadros de texto (type="text"), contraseñas con asteriscos (type="password"), envío (type="submit") y borrado de campos (type="reset")[cite: 16, 17, 18].
  • <textarea>: área de texto multilínea para comentarios largos, con rows (filas) y cols (columnas)[cite: 19, 20].
  • Checkbox y Radio: type="checkbox" permite marcar/desmarcar varias opciones independientes, mientras que type="radio" con el mismo name permite elegir solo una opción enviando su value[cite: 20, 21, 22].
  • <select>: lista desplegable con <option>; admite selección múltiple con multiple (y name="...[]") y agrupaciones con <optgroup label="...">[cite: 22, 23, 25, 26].

4. JavaScript

JavaScript es un lenguaje interpretado orientado a documento que se embebe dentro de HTML (entre etiquetas <script> y </script>) para dar interactividad, y es sensible a mayúsculas y minúsculas[cite: 27, 28].

Conceptos clave del documento:

  • Salida y entrada: document.write() imprime en la página y prompt() pide datos por teclado (siempre devuelve texto, por lo que se usa parseInt() o parseFloat() para operar como números)[cite: 27, 31, 33, 38].
  • Variables y tipos: se declaran con let y pueden guardar enteros, decimales, cadenas de texto (entre comillas) o booleanos (true / false)[cite: 28, 30].
  • Condicionales y switch: estructuras if, if / else y condicionales anidadas para tomar decisiones, además de switch con case, break y default para evaluar valores exactos[cite: 35, 39, 41, 43, 44].
  • Ciclo while: repite un bloque mientras la condición sea verdadera, cuidando actualizar el contador y evitar ciclos infinitos[cite: 45, 47].

5. Estructuras switch, while, do/while, for

Las estructuras de selección múltiple y repetitivas permiten controlar el flujo de un programa en JavaScript sin repetir código innecesariamente, apoyándose en contadores y acumuladores.

Estructuras principales vistas en clase:

  • switch: evalúa igualdad exacta de una variable frente a distintos case (finalizando cada uno con break y usando default como opción por defecto).
  • while: evalúa la condición al inicio y repite el bloque mientras sea verdadera; si es falsa desde el principio, no se ejecuta.
  • do / while: ejecuta el bloque al menos una vez porque evalúa la condición al final del ciclo.
  • for: ideal cuando se conoce de antemano cuántas repeticiones se harán; recibe inicialización (preferiblemente con let), condición e incremento/decremento (++ / --).

6. Funciones

Una función agrupa un conjunto de instrucciones que resuelven parte de un problema para evitar repetir código y hacer el programa más ordenado y fácil de leer[cite: 61, 64].

Puntos clave de la clase:

  • Estructura y nombre: se declaran con function nombreFuncion(argumentos) { ... } usando un nombre descriptivo y respetando mayúsculas y minúsculas
  • Llamada (invocación): las instrucciones de una función solo se ejecutan cuando se la llama por su nombre (por ejemplo, mostrarMensaje()), y puede llamarse las veces que haga falta
  • Variables locales y entrada de datos: dentro de una función se pueden declarar variables locales (como let valor) y pedir datos por teclado con prompt()[cite: 65]

7. Funciones con parámetros por valor

Las funciones pueden recibir datos de entrada mediante parámetros (cuyos nombres no tienen que llamarse igual que las variables enviadas al llamarlas) y devolver un resultado usando return[cite: 66, 67, 69].

Puntos clave de la clase:

  • Paso de parámetros: al invocar la función, los valores o variables pasan en orden a los parámetros definidos entre paréntesis (por ejemplo, mostrarComprendidos(valor1, valor2))
  • Retorno con return: una función puede recibir varios parámetros, pero solo retorna un único valor, el cual puede guardarse en una variable o imprimirse directamente
  • Combinación con switch y cadenas: se puede usar return dentro de estructuras condicionales o switch para devolver textos o construir mensajes acumulando cadenas

8. Clase Date

La clase predefinida Date permite manejar fechas y horas en JavaScript creando instancias con el operador new, ya sea tomando la fecha y hora actual del equipo o pasando valores específicos[cite: 73, 75].

Puntos clave de la clase:

  • Creación de instancias: con new Date() se obtiene la fecha y hora actual, mientras que al pasar parámetros los meses empiezan en 0 (enero es 0 y diciembre es 11)[cite: 73]
  • Métodos get y set: permiten leer o cambiar año (getFullYear() / setFullYear()), mes (getMonth() / setMonth()), día del mes (getDate() / setDate()), horas, minutos y segundos[cite: 73]
  • Día de la semana: getDay() devuelve un número del 0 (domingo) al 6 (sábado), útil para formatear fechas legibles junto con estructuras como switch[cite: 74, 78, 79]

9. Clase Array y String

Los arreglos (Array) permiten guardar conjuntos de datos bajo un mismo nombre accediendo por índice desde 0, mientras que String representa cadenas de texto con propiedades y métodos para manipularlas[cite: 80, 83, 86].

Puntos clave de la clase:

  • Clase Array: se puede crear con new Array(n) o corchetes []; su longitud se consulta con .length y permite trabajar con vectores paralelos o arreglos anidados (matrices)[cite: 81, 83, 84, 85].
  • Clase String: se concatenan textos con + y se obtiene el total de caracteres con .length[cite: 86].
  • Métodos principales de String: charAt(pos) obtiene el carácter en esa posición, substring(inicio, fin) extrae un fragmento (sin incluir fin), indexOf(subcadena) busca su posición o devuelve -1, y toUpperCase() / toLowerCase() convierten a mayúsculas o minúsculas[cite: 86, 87, 88].
